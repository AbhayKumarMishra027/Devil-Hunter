# Devil-Hunter🎮
A Game which is enough to give you Adrenaline Rush! 

**A fast-paced, adrenaline-filled browser game made with HTML, CSS, and JavaScript.**

## Features
- Smooth controls with responsive gameplay
- Neon-themed UI for a modern look
- Obstacles and challenges to keep you engaged
- Works directly in any modern browser

## How to Play
1. Open `index.html` in your browser
2. Use arrow keys (or WASD) to control the player
3. Avoid obstacles and survive as long as possible
4. Collect power-ups to enhance gameplay

## Technologies Used
- HTML5
- CSS3
- JavaScript (vanilla)
